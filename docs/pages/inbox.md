# Inbox

<!-- page-route: /inbox -->

## 목적과 범위

메시지를 검색하고 읽음·미읽음·보관 상태를 체험합니다. 메시지와 변경은 페이지 메모리에만 있고 재마운트/새로고침하면 샘플로 돌아갑니다. 메일 서비스 연결·작성·답장·발송·영구 저장은 없습니다.

## 정보 구조와 주요 행동

PageHeader → 미보관 메시지의 미읽음 수와 샘플 안내 → 보기 탭/검색/목록 → 선택 상세입니다. 선택은 읽음 처리와 상세 제목 초점 이동을 수행합니다. 상세에서 읽음 상태와 보관/복원을 조작합니다. [화면 조합](../design/compositions.md)의 목록+상세 구조입니다.

## 조회·조작 계약

- 검색은 보낸 사람·제목·미리보기·본문을 대상으로 보기 탭과 결합합니다. 보기/검색 변경 시 선택 상세를 닫습니다.
- 미읽음 보기에서 읽어 목록에서 사라져도 해당 상세는 열어 둡니다. 읽음 전환도 상세를 유지합니다. 보관/복원은 상세를 닫고 검색창에 초점을 돌립니다.
- 빈 결과의 전체 보기는 검색과 보기를 초기화하고 선택을 해제합니다. 읽음·보관 변경 자체를 초기화하지 않습니다.
- 페이지 이동·정렬·내보내기는 없습니다. URL 복원은 조회 조건만 복원하며 메시지 변경을 영구화하지 않습니다.

## 상태별 화면

로컬 샘플을 즉시 표시하므로 네트워크 최초 로딩·재조회·오류·재시도 상태는 없습니다. 검색 없음, 미읽음 없음, 해당 보기의 빈 상태 설명을 구분하며 전체 보기로 복구합니다. 선택 전 상세는 선택 안내입니다. 변경 결과는 status 영역으로 알립니다. 브라우저 새로고침은 조회 조건을 보존하지만 로컬 샘플 변경은 되돌립니다.

## 반응형 동작

| 구간                | 배치·스크롤·초점                                                                                      |
| ------------------- | ----------------------------------------------------------------------------------------------------- |
| 모바일 `< 768px`    | 목록 또는 상세 하나만 표시합니다. 상세의 뒤로 가기는 원래 행, 행이 없으면 검색창으로 초점을 돌립니다. |
| 태블릿 `768–1279px` | 좁은 목록과 상세를 동시에 표시합니다. 선택 전 상세 안내를 유지합니다.                                 |
| PC `≥ 1280px`       | 목록 폭을 넓혀 상세와 병렬 표시합니다. 상세 조작은 필요 시 줄바꿈합니다.                              |

목록 제목/미리보기는 축약하고 선택 상세로 본문을 읽습니다. 긴 사용자 텍스트 처리 변경은 [긴 콘텐츠](../design/content-overflow.md)를 기준으로 실제 상세 폭을 확인합니다.

320–412px에서 글꼴을 200%로 확대하면 상단 메시지 수·보기 탭·상세 작업은 필요한 만큼 줄바꿈하고 높이를 늘립니다. 카드 바깥에 숨겨지는 탭이나 작업 문구가 없어야 합니다. 상세 발신자 정보는 날짜와 같은 행을 억지로 공유하지 않고 충분한 읽기 너비를 확보한 뒤 줄바꿈합니다. 뒤로 가기와 보관 이후의 초점 복귀는 확대 여부와 관계없이 유지합니다.

## 상태 소유권과 구현 근거

- URL: [라우트](../../src/app/routes/inbox.tsx), [조회 스키마](../../src/pages/inbox/model/search.ts)의 검색과 보기.
- Query: 사용하지 않습니다. [샘플 모델](../../src/pages/inbox/model/sample-messages.ts)에서 [화면의 로컬 상태](../../src/pages/inbox/ui/inbox-page.tsx)로 메시지를 초기화합니다.
- 임시 상태: 메시지 변경·선택과 선택 당시 조회 조건·알림·초점 대상. 영구 사용자 표시 설정만 공통 [국제화](../i18n.md)를 따릅니다.

## 수용 기준

- 같은 Inbox E2E의 `keeps inbox navigation and detail actions inside the card at 200% text`에서 412px 영어·320px 한국어의 미읽음 배지·탭·상세 작업 경계, 발신자 가독성, 터치 선택과 초점 복귀를 확인합니다.
- 미읽음/검색 조합·빈 결과 복구·URL: [Inbox E2E](../../e2e/analytics-inbox.spec.ts)의 `inbox combines unread and search filters and recovers from an empty result`.
- 읽음·미읽음·보관·복원: 같은 파일의 `inbox marks sample messages read and unread and restores an archived conversation`.
- 키보드 선택·반응형 초점: 같은 파일의 `inbox supports keyboard message selection and responsive focus recovery`.
- 메시지 자체가 URL 계약에 섞이지 않음: [스키마 테스트](../../src/pages/inbox/model/search.test.ts)의 `defaults omitted parameters and keeps only view state in the URL contract`.
