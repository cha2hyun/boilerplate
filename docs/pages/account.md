## 목적과 범위

로그인한 데모 사용자가 자신의 이름·이메일·역할·상태를 확인하고 워크스페이스 사용자 목록으로 이동한다. 브라우저 환경 설정은 Settings에서 바꾼다.

## 정보 구조와 주요 행동

공통 헤더 다음에 사진과 전체 이름을 표시한다. 데모 프로필의 이름은 `soohyun`, 성은 `chae`, 닉네임은 `soohyun`이다. 사용자 보기 링크는 내부 구성원 목록으로 이동한다. 헤더의 아바타 메뉴 상단에는 현재 계정의 사진·전체 이름·이메일을 표시한다. 그 아래 **내 계정**은 이 프로필을, **워크스페이스 설정**은 이름·탐색 밀도·테마를 바꾸는 설정 화면을 연다. 하단의 **로그아웃**은 현재 탭 세션을 종료한다.

Google의 아바타 메뉴는 사진·이름·이메일로 현재 계정을 식별하게 하고, GitHub는 프로필과 사용자가 실행할 설정 바로가기를 묶는다. Blueprint도 현재 계정을 먼저 보여 주고 실제로 연결된 두 화면만 메뉴에 둔다. [Google 계정 도움말](https://support.google.com/accounts/answer/19870?hl=en) · [GitHub 프로필 메뉴 개편](https://github.blog/changelog/2025-09-04-profile-menu-enhancements-in-global-navigation/)

## 조회·조작 계약

세션에 기록된 고정 샘플 ID로 구성원 상세를 조회한다. 주소에서 다른 계정 ID를 지정하거나 여기에서 프로필을 편집하지 않는다. 비로그인 직접 진입은 로그인으로 이동하며 성공하면 원래 경로를 복원한다. API 모드에서 샘플 세션은 운영 API 접근을 제공하지 않는다.

## 상태별 화면

최초 조회 중에는 프로필 공간에 로딩 상태를 표시한다. 조회 실패와 없는 계정은 복구 안내·재시도를 제공한다. 재조회 중에 캐시된 프로필은 보존된다. 메뉴와 내 계정 화면은 사진을 불러오는 동안 원형 스켈레톤을, 주소가 없거나 사진을 불러오지 못하면 이니셜을 표시한다. 메뉴를 펼친 상태에서 프로필 자체를 가져오지 못하면 다시 시도할 수 있고 내 계정·설정·로그아웃도 사용할 수 있다.

## 반응형 동작

기본 글꼴에서 768px 미만은 프로필 이름표 아래에 값을 한 열로 표시한다. 768px부터는 이름표와 값을 같은 행에 배치한다. 긴 이름과 이메일은 어느 구간에서든 줄바꿈한다. 상단 메뉴는 모바일·태블릿에서 아바타만 보이고 PC에서 닉네임까지 보인다. 사용자 목록 이동과 계정 메뉴는 키보드로도 가능하다.

[사용자 흐름 E2E](../../e2e/workspace-users.spec.ts)의 `restores a protected account in this tab and requires sign-in after logout`는 이메일 값이 640·767px에서는 이름표 아래, 768px에서는 같은 행에 표시되는지 두 요소의 위치로 확인한다.

## 상태 소유권과 구현 근거

[라우트](../../src/app/routes/account.tsx)는 데모 세션을 확인하고, [내 계정 화면](../../src/pages/account/ui/account-page.tsx)은 Query의 상세 결과를 읽는다. 계정 메뉴는 [앱 셸](../../src/widgets/app-shell/ui/header-actions/account-menu.tsx)이 소유한다.

## 수용 기준

메뉴를 열면 현재 프로필을 확인하고 키보드로 내 계정·워크스페이스 설정·로그아웃을 선택할 수 있다. Escape로 닫으면 초점이 헤더 아바타로 돌아간다.

[사용자 흐름 E2E](../../e2e/workspace-users.spec.ts)는 비로그인 직접 진입, 샘플 로그인, 내 프로필 표시, 새로고침, 로그아웃 이후 브라우저가 보관했던 문서를 복원하는 경우와 재진입과 내부 사용자 목록 이동을 확인한다.
