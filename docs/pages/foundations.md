## 목적과 범위

제품을 만드는 사람이 디자인 원칙·레이아웃·문구·국제화·숫자/피드백의 차이를 예제로 이해합니다. 설정이나 데이터 관리 화면이 아니며 예제의 성공/오류 전환은 실제 서버 요청을 실행하지 않습니다.

## 정보 구조와 주요 행동

PageHeader → 기본/레이아웃/콘텐츠/피드백 탭입니다. 기본은 서체·색상·구성, 레이아웃은 Stack·아이콘 탐색·화면 구간, 콘텐츠는 문구·언어·시간대 미리보기, 피드백은 숫자/모션·오류 복구·로딩 예제입니다. [화면 조합](../design/compositions.md)의 원칙 설명+체험 구조입니다.

## 조회·조작 계약

- 예제 탐색 레일은 선택 표시만 바꾸고 실제 페이지 이동을 하지 않습니다. 콘텐츠의 언어·시간대 미리보기는 해당 예제만 바꾸며 앱 언어·시간 설정을 저장하지 않습니다.
- 숫자 형식·구분자·축약·통화 기호·모션·값 변경은 예제 숫자에만 적용합니다. 통화 선택은 숫자 표시 형식의 체험이며 실제 환율 변환 기능이 아닙니다. 모션을 켰을 때만 재생을 사용합니다.
- 오류/복구 버튼은 로컬 상태를 전환합니다. 전역 초기화·내보내기·서버 저장은 없습니다. 탭/예제는 URL에 보존하지 않고 예제가 재마운트되면 로컬 상태를 초기화합니다.

## 상태별 화면

페이지 Query가 없어 최초 로딩·캐시 재조회·네트워크 실패·빈 목록은 없습니다. skeleton과 오류/성공 Alert는 독립적인 설명 예제이며 요청 성공을 증명하지 않습니다. 복구 예제의 상태 변경은 live 영역으로 전달합니다. 숫자 모션은 공통 reduced-motion·접근 가능한 전체 값 계약을 따릅니다.

## 반응형 동작

| 구간                | 배치·스크롤·초점                                                                            |
| ------------------- | ------------------------------------------------------------------------------------------- |
| 모바일 `< 768px`    | 예제 1열. 탭은 자체 가로 스크롤, 액션은 줄바꿈하고 코드 설명은 본문 밖으로 넘치지 않습니다. |
| 태블릿 `768–1279px` | 예제 카드 2열, 넓은 설명 카드가 두 열을 사용합니다.                                         |
| PC `≥ 1280px`       | 기본 카드 2열을 유지하며 내부 구성/로딩 예제는 3열, 숫자 옵션은 내부 2열을 사용합니다.      |

예제에서 보이는 축약은 전문 확인 경로와 함께 검토하며 문구/숫자 폭은 [긴 콘텐츠](../design/content-overflow.md), [숫자 표시](../number-formatting.md)를 따릅니다.

## 상태 소유권과 구현 근거

- URL/Query: [라우트](../../src/app/routes/foundations.tsx)는 페이지별 조회 조건/Query를 만들지 않습니다.
- 임시 상태: [화면과 예제](../../src/pages/foundations/ui/foundations-page.tsx)의 탭·레일·언어/시간대·숫자·복구. 전역 언어는 미리보기의 출발값으로만 읽습니다.
- 표현 소유: [숫자 표시](../number-formatting.md), [레이아웃](../design/layout.md), [문구](../design/writing.md), [국제화](../i18n.md). 기본값·색상·번역은 소유 코드/문서에 둡니다.

## 수용 기준

- 숫자 형식·통화 기호·축약·모션과 예약 폭: [workspace E2E](../../e2e/workspace.spec.ts)의 `switches shared number formats and keeps compact motion text within its reserved width`.
- 헤더/화면 구간별 탐색: 같은 파일의 `keeps page titles and header badges consistent through responsive sidebar navigation`. 서체 로딩: `loads Korean and Latin Pretendard subsets at only the three approved weights`.
- 레일·언어/시간대 미리보기·복구 토글 전체는 현재 개별 자동 검사가 없습니다. 변경 시 예제가 전역 설정을 쓰지 않는지와 키보드 조작을 수동 확인합니다.
