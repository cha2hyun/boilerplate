# 작업 계획: 디자인 규칙과 어드민 샘플 확장

상태: 구현 완료 — 2026-11-03, 원격 CI 미실행

후속 변경(2026-11-05): UI 폰트는 버전을 고정한 jsDelivr CDN으로 전환했습니다. 아래 자체 호스팅·검증 기록은 최초 구현 당시의 결과이며, 현재 제공 방식은 [타이포그래피](../design/typography.md)를 따릅니다.

## 완료 조건

- Pretendard 동적 subset을 자체 호스팅하며 400/500/600 세 가지 두께만 사용한다.
- 무채색 shadcn 토큰을 기본으로 유지하고 단일 brand 색상 및 의미별 사용 규칙을 선언한다.
- 기존 스타일을 유지한 Analytics, Orders, Customers, Inbox 페이지를 사이드바와 명령 검색에 연결한다.
- PC(1280px 이상), 태블릿(768–1279px), 모바일(768px 미만)에서 탐색과 콘텐츠를 사용할 수 있다.
- 테스트는 GitHub Actions가 기본 실행 위치이며 로컬 전체 테스트를 기본 작업 절차에서 제거한다.

## 구현 경계

폰트/토큰, 주문/고객 샘플, 분석/받은편지함 샘플, 탐색/가드레일/문서, CI 구성을 분리한다. 새 샘플은 가상 데이터를 명시하고 실계정·결제·메일 발송 기능을 주장하지 않는다. 기존 shadcn 컴포넌트를 조합하고 화면별 UI primitive/CSS는 만들지 않는다.

참고 화면: shadcn blocks의 dashboard/sidebar, Shadcn UI Kit의 기본 대시보드·주문 목록·웹 분석·메일·사용자 목록. 참조는 공개 데모의 정보 구조와 상호작용 패턴에 한정하며 유료 템플릿 소스를 복사하지 않는다.

## 검증

- 폰트 패키지의 선택된 3개 weight/unicode-range 및 실제 한국어/영문 glyph 로딩을 확인한다.
- 새 가드레일만 대상으로 필요한 회귀 검증을 하고, 변경 파일 lint/typecheck를 수행한다.
- 통합 시 프로덕션 번들을 한 번 빌드하여 세 화면 크기의 핵심 UI를 시각 점검한다.
- 전체 단위/E2E는 로컬에서 실행하지 않는다. CI 설정과 카테고리별 실행 명령을 제공한다.
- 원격 CI 실행 여부는 실제 push/PR 결과와 구분해 보고한다.

## 완료 기록

- Pretendard 1.3.9의 400/500/600 unicode-range subset, 단일 brand 의미 토큰, Typography 표본과 디자인 규칙을 추가했다.
- Analytics/Orders/Customers/Inbox와 그룹별 탐색·명령 검색을 연결했다. 기존 shadcn UI 형태를 유지했다.
- 정적 `pnpm check` 통과. 이후 초점 보완 변경은 대상 ESLint/포맷 검사와 최종 통합 빌드로 확인했다.
- 폰트 전용 확인에서 세 weight의 한글/영문 glyph가 같은 출처로 로드됨을 확인했다. 새 weight/color 가드레일 회귀 검사만 이름으로 선택해 5개 통과했다.
- 생산 번들을 PC 1440px Analytics, 태블릿 834px Inbox, 모바일 412px Orders에서 직접 확인했다. 가로 페이지 넘침 없이 탐색/메시지 상세/주문 Sheet를 사용할 수 있었다. Components의 세 weight와 dark 의미 토큰도 확인했고 브라우저 오류·경고가 없었다.
- 전체 단위/E2E는 이 확장 작업에서 실행하지 않았다. CI는 단위 3범주, 브라우저 2범주/3화면 크기와 번들 공유로 구성했고 설정·범주 매핑·YAML을 정적으로 확인했다.
- commit/push/Actions 실행은 하지 않았다. 원격 결과는 push/PR 후 확인해야 한다. 확인용 서버와 임시 브라우저 탭은 종료했다.
