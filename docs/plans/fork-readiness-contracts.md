# 작업 계획: 포크 후 변경과 검증 경계 보강

상태: 구현 완료 · 원격 검증 기록

## 문제와 완료 조건

- 제품 기본값을 바꾼 뒤에도 설정 초기화의 폼과 저장값이 일치합니다.
- 검색 입력과 결과 목록에 한국어·영어 접근 가능한 이름을 제공합니다.
- 잘못된 API 환경 값은 Vite 시작·빌드 설정 단계에서 거부합니다.
- 실제 HTTP 쓰기의 URL·입력·응답·캐시 동기화와 새 단위 테스트의 범주 배정을 검증합니다.
- 모든 PR에 최종 CI Gate가 존재하며 코드 변경의 품질·브라우저 실패나 취소는 병합을 차단합니다. 문서만 바뀌면 설치·빌드·브라우저 검사를 생략합니다.

## 확인한 근거

- 기준 main은 `806b9ac`입니다. 단위 238건·가드레일 46건·브라우저 88건의 Actions는 통과했지만 포크 후 변경 계약의 빈틈이 있었습니다.
- Settings의 reset 문구는 store 기본값과 중복됐고, 실제 Chromium 접근성 트리에서 검색 입력 이름은 비어 있었습니다.
- 환경 parser의 모듈 평가 예외는 앱의 비동기 시작 catch보다 먼저 발생했습니다.
- HTTP PATCH/DELETE의 구체적인 요청 계약과 단위 테스트 범주의 완전성을 검사하지 않았습니다.
- 원격 main에는 보호·required checks·rulesets가 없었습니다. 기존 workflow 경로 필터를 그대로 필수 검사로 지정하면 문서 PR에 검사가 만들어지지 않습니다.

## 변경 경계

- 환경 설정·설정 폼·검색 이름의 소유권을 정리하고 관련 계약 테스트를 기존 범주에 추가합니다.
- CI는 가벼운 변경 분류와 최종 gate를 추가합니다. production 빌드 1회, 브라우저 최대 2-job/2-worker, 짧은 artifact 보관은 유지합니다.
- 검증된 gate가 실제 PR에서 성공한 뒤 main 보호에 적용합니다. 기존 규칙이 생겼다면 다시 확인하고 보존합니다.
- 포크한 저장소에는 원격 보호 설정이 자동으로 적용되지 않으므로 도입 문서에 설정과 확인 방법을 기록합니다.
- 인증·백엔드·배포 기능, 새 UI 디자인과 새로운 패키지 의존성은 이번 범위에 포함하지 않습니다.

## 실행과 검증

1. 각 책임의 좁은 회귀 테스트와 `pnpm check`를 수행합니다. 전체 로컬 테스트·빌드는 실행하지 않습니다.
2. 기능별 커밋·푸시 후 PR Actions의 단위·가드레일·production 브라우저 결과를 확인합니다.
3. 코드 변경·문서 전용 변경과 gate 실패 조건을 검증하고, 필수 상태 검사 설정을 읽어 적용 결과를 확인합니다.
4. main 병합 후 최신 SHA의 Actions와 열린 Dependabot PR·보안 알림을 재확인합니다.

## 완료 기록

- 설정 초기화의 기본값 중복을 제거하고 영어·한국어 cmdk 입력/목록 이름을 연결했습니다. 실제 Chromium 접근성 트리에서 두 언어의 이름을 확인했습니다.
- 공유 환경 parser를 Vite 설정 검증과 런타임에 연결했습니다. 모드·envDir·파일/프로세스 우선순위를 실제 resolveConfig로 검사했습니다.
- HTTP 쓰기 계약과 단위 테스트 범주 완전성 검사를 추가했습니다. .test/.spec TS/TSX를 지원하고 미분류·중복을 실패 처리합니다.
- CI 분류·gate를 구현하고 수동 부분 실행은 Manual CI result로 구분했습니다. 파일 rename·PR merge base·실패·취소·누락 회귀 검사를 통과했습니다.
- 관련 단위 검사 33건과 새 가드레일 검사 19건, pnpm check가 통과했습니다. 전체 로컬 테스트·빌드는 실행하지 않았습니다.
- [PR #19](https://github.com/cha2hyun/boilerplate/pull/19)의 [전체 CI](https://github.com/cha2hyun/boilerplate/actions/runs/41859156042)가 통과했습니다. 단위 240건·가드레일 65건·브라우저 88건이 성공했고, 화면 크기와 무관한 메타데이터 중복 2건은 기존 조건대로 제외했습니다.
- 코드 병합은 `197082f`이며 [main 코드 검증](https://github.com/cha2hyun/boilerplate/actions/runs/41860244780)도 통과했습니다. 문서 전용 실행은 이 완료 기록 PR의 CI에서 changes/gate 성공 및 quality/browser 생략을 대조합니다.
- main 보호를 적용한 후 API로 재조회했습니다: GitHub Actions(app 15368)의 CI Gate·Conventional PR title 필수, 최신 base 요구, 관리자 포함, PR 필수, 타인 승인 수 0, force push·삭제 차단. PR #19는 보호 우회 없이 병합했습니다.
- 이 기록은 2026-11-05 확인한 원격 설정입니다. 포크에는 자동 적용되지 않으며 이후 변경 여부는 원격에서 다시 확인해야 합니다.
