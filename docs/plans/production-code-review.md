# 작업 계획: 독립 시니어 리뷰와 확인된 결함 수정

상태: 완료 — 2026-11-03, 원격 CI 미실행

## 완료 조건

- Astra 6 xhigh 리뷰어 세 명이 아키텍처/데이터, UI/접근성, 테스트/CI를 독립적으로 평가하고 점수와 코드 근거를 제시한다.
- 통합 담당자가 실제 코드와 재현 조건을 확인해 타당한 지적만 수정한다. 취향에 따른 UI 변경이나 불필요한 추상화를 추가하지 않는다.
- 수정 후 같은 기준으로 재평가하고 점수의 한계 및 미검증 항목을 함께 기록한다.

## 평가 범위

운영용 프런트엔드 기반의 코드 품질을 평가한다. 문서에 명시된 실제 인증/백엔드/배포의 부재를 구현 결함으로 취급하지 않으며, 운영 준비도와 코드 품질 점수를 혼동하지 않는다.

- 아키텍처·데이터: 가중치 40%. 경계, 입력/응답 계약, 상태 소유권, 실패/경합 처리.
- UI·접근성: 가중치 30%. 사용자 흐름, 초점/키보드, 반응형, 유지보수성과 성능.
- 테스트·CI: 가중치 30%. 실패 탐지력, 결정성, 실행 경로, 보안, 비용과 AI 가드레일.

## 검증 정책

리뷰는 우선 읽기 전용으로 진행한다. 수정한 결함의 필요한 최소 회귀 검사만 선택할 수 있으며 전체 로컬 단위/E2E/브라우저 테스트를 실행하지 않는다. 정적 검사와 필요한 파일/테스트 이름별 결과를 기록한다. 원격 Actions는 실제 실행 여부를 구분하고 commit/push는 수행하지 않는다.

## 승인된 수정 경계

- shared API/env 및 entities/project: 초기 요청과 mutation 경합, 응답 deadline, API 주소 검증과 관련 회귀 검사. API 계약 문서를 함께 갱신한다.
- project editor 및 탐색/테이블 UI: 짧은 화면의 Dialog 스크롤, 오버레이 닫힘/필터 초기화 초점 복귀. 기존 E2E에 회귀 조건을 추가하되 전체 실행은 CI에 맡긴다.
- 설정/가드레일: E2E 타입 검사 포함, 등록되지 않은 내부 레이어와 JSX role literal의 우회 차단.
- 후속 사용자 요청: 로컬 개발 서버를 계속 유지하고 Query/Router Devtools를 공식 통합 패널로 변경한다. 개발 도구 자체의 확인에만 개발 모드 점검을 사용한다.
- 후속 사용자 요청: Devtools trigger를 32px로 줄이고, SSR 없이 경로별 메타/정적 HTML shell과 favicon·bookmark·OG 자산을 구성한다. 실제 공개 도메인은 설정으로 받는다.

## 완료 기록

리뷰 결과와 수정 판단은 `docs/reviews/production-code-review.md`에 기록한다.

- 독립 평가와 확인된 10개 수정(추가 main landmark 포함)을 완료했다. 가중 평균은 87.3에서 95.1이며 운영 배포 승인이나 전체 CI 통과를 의미하지 않는다.
- 로컬 전체 테스트는 실행하지 않았다. 변경 계약의 대상 검사, 통합 `pnpm check`, production build가 통과했다.
- 최종 번들의 8개 경로 HTML/404와 Devtools UI 미포함을 확인했다. preview 원문 응답에서 발견한 디렉터리 index 우선순위 문제를 수정하고 모든 경로/아이콘/이미지의 HTTP 응답을 확인했다.
- 개발 전용 통합 Devtools에서 Query/Router 패널을 확인했고, 실행 버튼은 32×32px다. 개발 화면에서 main landmark는 1개이며 페이지 이동 후 OG/canonical이 현재 경로로 변경된다.
- 사용자 요청으로 `http://127.0.0.1:5173/` 개발 서버와 브라우저 탭은 유지한다. 확인용 4173 preview 서버는 종료했다. commit/push/Actions는 실행하지 않았다.
