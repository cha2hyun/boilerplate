# 프로젝트 상세에서 편집하기

## 완료 조건

홈 요약 표와 프로젝트 목록의 이름 버튼은 같은 읽기 전용 상세 패널을 연다. 수정 버튼으로 편집창을 열고, 저장하거나 취소하면 상세로 돌아간다. 행 메뉴의 명시적인 수정·삭제와 새 프로젝트 생성 흐름은 계속 동작한다.

## 변경 경계

프로젝트 표가 상세와 편집창의 초점·표시를 연결하고, 라우트는 검증된 `detail`로 열린 프로젝트를 복원한다. 이름이나 목록의 표시 순서를 키로 사용하지 않는다. 상세는 프로젝트 목록 Query의 기존 데이터와 상태를 사용한다. 홈의 기간과 표의 조회 조건을 상세를 열고 닫을 때 보존한다.

## 검증

관련 URL 단위 검사와 모바일·태블릿·PC의 브라우저 검사로 상세 → 수정 → 복귀, 새 탭·뒤로/앞으로와 초안 보호를 확인한다. 변경 커밋과 병합 커밋의 CI를 확인한다.

## 로컬 확인

홈과 목록에 대해 정적 검사·프로덕션 빌드 및 URL·표·편집 단위 검사 11건을 통과했다. 모바일 크기의 WebKit에서 상세를 열고 수정 모달을 취소하거나 저장한 후 같은 상세로 돌아가는 것과, 이름을 바꾼 프로젝트의 새 버튼으로 초점이 복원되는 것을 확인했다.
