# 캐시·로딩·디자인 문서 리뷰

2026-11-04 작업 스냅샷입니다. 현재 규칙은 [문서 지도](../README.md)에서 찾고, 이 기록을 구현 계약으로 복제하지 않습니다.

## 독립 검토

사용자가 지정한 Astra xhigh 에이전트가 변경 코드를 읽기 전용으로 검토했습니다. 초기 **8.2/10**, 수정 후 **9.2/10**입니다. 점수는 이번 변경의 코드 검토 의견이며 운영 인증이나 전체 서비스 준비 완료를 의미하지 않습니다.

| 지적                                                    | 수정                                                                                                    |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| 열린 주문/고객 상세가 Query 재조회 결과를 반영하지 않음 | ID만 UI 상태로 보관하고 최신 응답에서 상세를 계산. 삭제 시 닫기·초점 복귀·동일 ID 재등장 시 재오픈 방지 |
| 긴 고객명/이메일이 고정 표의 다음 열을 침범             | 셀 내부 축소·생략, 전체 값 title/접근 가능한 이름, 상세 화면 줄바꿈                                     |
| API의 임의 fill이 차트 색상 규칙을 우회                 | 응답 스키마/fixture에서 스타일 제거. UI가 chart 토큰 소유. 응답 경계 회귀 추가                          |
| Skeleton이 움직임 줄이기를 무시                         | 공유 Skeleton에서 reduced-motion pulse 중단                                                             |

재검토에서 위 네 건의 수정과 검색 단축키의 겹침 수정, Foundations의 한국어 언어 표기를 확인했습니다. 추가 P0–P2 지적은 없었습니다. 검토 에이전트는 테스트나 빌드를 실행하지 않았습니다.

## 실제 확인 범위

- 로컬 `pnpm check`의 포맷·ESLint·타입·아키텍처 검사 통과.
- 숫자 모션 13개 대상 테스트 통과. 완료 시간·캐시 재진입에 해당하는 remount·동일 값 rerender·reduced motion·정리 동작 포함.
- 목업 HTTP/캐시 및 기존 프로젝트 취소 경쟁 관련 선택 검사 통과. 리뷰 후 추가한 스타일 제거 회귀와 상세 갱신 회귀는 Actions에서 실행한다.
- production build 및 Overview 데스크톱의 cold/warm/stale cache·실제 요청 수·카드 치수 E2E 1건 통과. 전체 로컬 suite는 실행하지 않았다.
- Foundations를 PC/태블릿/모바일에서 확인했다. 접힌 사이드바 로고·메뉴·프로필 가로 중심은 모두 33px, 버튼 내부 세로 중심 오차는 0px였다. 태블릿 검색 아이콘과 단축키 간격은 8px로 겹치지 않았다.
- 전체 단위/브라우저 검증의 최종 결과는 해당 PR의 Actions checks를 기준으로 한다. cache E2E는 네 페이지와 세 화면 크기를 검사하고, commerce E2E는 갱신·삭제·긴 문자열·초점 복귀를 검사한다.

Lighthouse는 이번 작업에서 다시 측정하지 않았다. 과거 성능 점수를 현재 변경의 결과로 사용하지 않는다.
