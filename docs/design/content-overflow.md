# 긴 콘텐츠와 전체 값

내용이 길어져도 페이지 전체가 가로로 밀리거나 필요한 정보가 사라지지 않아야 합니다. 축약은 데이터 정책이며 공간 부족을 해결하는 숨은 formatter 옵션이 아닙니다. 숫자의 정밀도·통화·환율은 [숫자 표시](../number-formatting.md)와 [국제화](international-design.md)를 유지합니다.

## 표시 경계별 정책

| 내용                                   | 정책                                                                     | 현재 소유 예제                                |
| -------------------------------------- | ------------------------------------------------------------------------ | --------------------------------------------- |
| 페이지 제목·설명                       | 줄바꿈, 고정 높이/줄 제한 없음                                           | 공통 `PageHeader`                             |
| KPI 값·금액                            | 같은 글자 크기, `wrap`으로 전체 문자열 표시, 자동 compact 없음           | `MetricCard` + `NumberDisplay`/`MoneyDisplay` |
| 목록 이름·이메일·주문 번호             | `min-w-0` + `truncate` 허용; 화면 낭독기 이름과 상세 열기로 전체 값 확인 | Orders·Customers 목록/Sheet, Inbox 목록/본문  |
| 상세 이름·이메일·본문·긴 식별자        | `wrap-anywhere`, 전체 내용 표시                                          | Orders·Customers Sheet, Inbox 상세            |
| 상세로 열리지 않는 분석 경로·유입 이름 | `whitespace-normal` + `wrap-anywhere`; 생략하지 않음                     | Analytics 표                                  |
| 넓은 표                                | 표 내부에서 스크롤, 읽을 수 있는 최소 열 너비 유지                       | Orders·Customers의 `Table.containerProps`     |
| 표 금액·수량                           | formatter 전체 문자열 유지, 필요한 경우 셀 안 줄바꿈                     | Orders·Customers 숫자 셀                      |

CSS의 `truncate`는 DOM의 전체 문자열을 유지하지만 hover `title`만으로 터치·키보드 사용자의 전체 확인을 대신하지 않습니다. 목록에서 생략한 내용은 기존 상세 버튼/행으로 열어 확인할 수 있어야 합니다. 별도 상세 화면이 없는 값은 줄바꿈을 우선합니다. 전체 값을 숨긴 Tooltip을 임의로 추가하거나 클립보드 기능을 만들어 처리하지 않습니다.

## 공통 크기 책임

- 유연한 grid/flex 자식에는 `min-w-0`, 고정 아이콘·avatar에는 `shrink-0`를 둡니다. 긴 문자열이 최소 콘텐츠 너비로 부모를 밀지 않도록 합니다.
- 일반 문장은 자연스러운 줄바꿈을 유지합니다. 이메일·URL·식별자처럼 공백이 없을 수 있는 콘텐츠에는 `wrap-anywhere`를 사용합니다. 이 속성은 단어가 들어갈 공간이 없을 때만 분리하고 최소 콘텐츠 너비 계산에도 반영됩니다.
- 행에 긴 금액과 설명이 함께 있으면 `HStack wrap` 또는 유연한 너비를 사용합니다. 숫자에 무조건 `shrink-0`를 부여해 옆 내용을 밀어내지 않습니다.
- 가로 스크롤은 표/코드처럼 구조 자체가 넓은 경우에 한정합니다. `overflow-hidden`으로 페이지 결함을 숨기거나 본문을 고정 높이로 자르지 않습니다.

## 숫자의 줄바꿈과 모션

`NumberDisplay`와 `MoneyDisplay`의 `wrap` 기본값은 `false`입니다. 기존 한 줄 표시가 필요한 호출부는 바뀌지 않습니다. KPI와 좁은 상세 요약에서는 `wrap`을 명시합니다. 한 줄로 들어가는 값은 그대로 표시하고 폭을 넘는 문자열은 줄바꿈합니다. 기호·구분자·정밀도를 다시 조립하거나 소수점·통화 기호를 제거하지 않습니다.

`NumberDisplay`는 최종값과 애니메이션 중간값에 같은 줄바꿈 규칙을 적용하고 그중 가장 큰 영역을 미리 예약합니다. 화면 낭독기는 기존처럼 줄바꿈 없는 최종 문자열 한 번만 읽습니다. `wrap` 변경은 모션을 재시작하지 않으며 300ms, reduced motion, 정적 기본값 계약을 유지합니다.

`MetricCard`는 숫자 두 줄과 footer 두 줄을 미리 확보합니다. 지원 화면 폭의 일반 USD/KRW 샘플은 로딩/성공 카드 치수를 유지합니다. 예외적으로 더 긴 레이블·설명·값은 잘리지 않도록 확장합니다. 이런 데이터가 제품의 일반 범위가 된다면 공통 예약 공간과 검증 데이터를 함께 조정하고, 특정 페이지만 글자 크기를 줄이거나 고정 높이로 숨기지 않습니다.

## 확인 기준

- 한국어·영어와 USD·KRW, 모바일·태블릿·PC에서 같은 역할의 값 크기와 간격을 비교합니다.
- 긴 공백 없는 제목·이메일·경로, 큰 통화 값, 여러 줄 설명을 확인합니다. 문서 너비가 viewport를 넘지 않고 세로 스크롤로 전체 내용을 읽을 수 있어야 합니다.
- 표에서는 가로 스크롤·키보드 진입점·전체 값·상세 버튼 초점을 확인합니다. 목록 생략과 상세 전체 표시를 함께 확인합니다.
- 표준 데이터의 로딩/성공 카드 치수 및 모션 중 예약 너비는 [로딩과 모션](../loading-and-motion.md)의 기준으로 검사합니다. CSS 줄바꿈의 실제 기하 검증은 브라우저에서 수행합니다.
